# La Estampería – Sitio Web

Sitio web oficial de **La Estampería** (`@laestamperia_cz`), negocio de personalización textil mediante tecnología DTF.

## 🎨 Tecnologías

- HTML5 semántico
- CSS3 personalizado (sin frameworks)
- JavaScript vanilla
- Google Fonts (Bebas Neue + Inter)
- Font Awesome 6 (iconos)

## 🗂️ Estructura

```
/
├── index.html     # Página principal (una sola página)
├── styles.css     # Estilos completos
├── script.js      # Interactividad
└── README.md
```

## 📄 Secciones

1. **Navbar** – Fijo con efecto scroll, menú hamburguesa en móvil
2. **Hero** – Titular impactante, CTAs, estadísticas
3. **Servicios** – 6 tarjetas con servicios detallados
4. **Tecnología DTF** – Explicación de la tecnología con iconos
5. **Galería** – Grid con filtros por categoría
6. **Proceso** – 4 pasos visuales
7. **Testimonios** – 3 reseñas de clientes
8. **Contacto** – Métodos de contacto + formulario
9. **Footer** – Links, redes sociales

## 🎨 Paleta de colores

| Color | Hex |
|-------|-----|
| Rojo principal | `#e53935` |
| Negro fondo | `#0d0d0d` |
| Oscuro tarjetas | `#111111` |
| Blanco texto | `#ffffff` |

## 🚀 Uso

Abrir `index.html` directamente en el navegador o servir con cualquier servidor estático.
